# Ink & Strata: publishing media

Public hosting for finished videos, so Metricool can fetch them by URL when posts are scheduled.

- Files: `media/YYYY-MM-DD/<random-id>.mp4`. Random names keep links unguessable.
- Each file is removed once Metricool has imported it and the post is live.
- Source code, scripts and research live in the private `lalapert/real_fact` repository, not here.
